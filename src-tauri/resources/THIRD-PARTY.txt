Mednafen Play is an independent frontend and window adapter by GameTranslate.
It is not an official Mednafen release. GameTranslate adds the library, approachable
settings UI, interface translations, appearance controls and window integration.
Emulation code and original contributions remain owned by their respective authors.

Linux/macOS compile the original emulation source with GameTranslate's separately
written display/input adapter linked into the executable. This is a custom build.

SDL — Sam Lantinga and SDL contributors, zlib license (SDL-LICENSE.txt).
On Windows the upstream DLL is preserved as SDL2_original.dll; SDL2.dll is the
separate GameTranslate host adapter using SDL 2.28.5 headers. Linux/macOS link our
display adapter and load the platform SDL library; its version is recorded in
HOST-MANIFEST.json. The adapter forwards SDL calls and integrates presentation
and input. It is not an upstream SDL release. Complete adapter source and build
scripts are included in the frontend source release/tag.
